Field guide / Run the workflow

Keep a marketing workflow recoverable when an AI plan reaches a limit

Provider limits and interrupted sessions are normal operational events. A recoverable workflow leaves the operator with a clear file and next step rather than forcing them to reconstruct the job from memory.

Practical guideFoundry editorial
Use this on a real job

Keep the current product, offer, sources, and decision owner beside the draft. The checklist works with any writing tool.

Checkpoint the job, not just the conversation

Keep the approved brief in a local file. Save source paths, the current offer, and exact approved wording beside the draft. Write down what has been completed, what the reviewer rejected, and which decisions remain open. A chat summary can help, but it should point to real files and versions.

When a provider pauses, stop adding new work to the same thread. Inspect the latest saved artifact. Determine whether the maker finished a concept, whether the reviewer started, and whether any output is partial. Resuming from a specific unfinished task is safer than repeating the whole brief and hoping the second run remembers the first.

Minimum continuation record

  • Objective and acceptance criteria.
  • Working folder and output file names.
  • Approved source files and their latest versions.
  • Completed sections and known defects.
  • Pending human decisions and the next safe action.

A continuation should not silently choose a new provider, create a new offer, or treat an old acceptance as approval for new text. If a compatible provider is available, the operator should see the handoff and decide whether to continue with it.

Test recovery with a real interruption

In a pilot, interrupt a sample campaign after the first concept and again during review. Restart the app and verify that the file, objective, sources, and open decisions survive. The practical measure is whether a new worker can identify the next step without inventing progress. Foundry’s provider handoff is a pilot feature to verify this way, not a promise of uninterrupted work.

Put the method to work

Foundry’s web planner can turn this into a structured campaign brief. The desktop pilot is a separate local workflow under review.
