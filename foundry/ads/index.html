03 / AI workflow

Keep the AI. Add a review step.

Short copy

Already use Claude Code or Codex? Keep the AI. Give the next ecommerce campaign a brief, a reviewer and a file you can accept. Foundry is a separate Windows pilot; your provider plan remains separate.

Read long copy

Claude Code and Codex can do serious work. Foundry's pilot is a focused workflow around them: define the ecommerce result, bring approved sources into one local project, let a maker and reviewer work from the same brief, then inspect the file before accepting it. This is not a claim that Foundry has a better model or that it can run your live store. The phone page prepares the mission; the Windows desktop runs the agents. Build the brief and judge the workflow against your current process.
