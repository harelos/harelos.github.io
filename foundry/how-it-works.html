How it works

From a rough idea to a file you can review.

The first workflow stays deliberately small: one product, one offer, approved source material, distinct concepts, and an operator decision at the end.

Step by step

The work has an owner at every point.

Preparation in the browser is available before desktop pilot access. Agent execution happens locally in the installed Windows app after provider sign-in and a chosen working folder.

01 / PLAN

Name the result

Use the web planner to define the campaign, evidence, constraints, and what must be true when it is done.

02 / CONNECT

Choose an eligible provider

In the Windows app, connect through the official Claude Code or Codex login and select a local folder.

03 / SUPPLY

Bring approved facts

Add the current offer, product facts, customer language, and files you are allowed to use.

04 / WORK

Maker and reviewer prepare the pack

One role drafts the campaign direction; another checks sources, repeated angles, and open questions.

05 / DECIDE

Review the file

Open, correct, accept, or export the handoff. Acceptance of a file is not approval to publish an ad.

The browser boundary

Your phone can prepare the job.

The planner stores the draft in the browser until you export it. It cannot access local files, operate the desktop app, connect to Shopify or Meta, or keep a live phone-to-desktop session. The export is an explicit handoff.

Practical questions

Before you start.

Do I need to connect a store or ad account?

No. The first workflow uses the facts and files you choose. It does not have a Shopify or Meta account connector.

Does the browser run AI agents on my computer?

No. The browser prepares and exports a mission file. Local agent work belongs to the Windows desktop pilot.

Will it publish the finished ads?

No. The result is a planning and review pack. Production and publishing remain separate decisions.

What if a provider session reaches a limit?

The pilot is designed to keep local project files and prepare a continuation. A compatible provider must be connected, and the operator approves a switch. Recovery still needs end-to-end pilot verification.
